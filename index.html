OSINT lead intelligence · Nethermind

GitHub Radar

Uses OSINT (open-source intelligence) on public GitHub activity to find crypto projects that may need an audit soon. It scores the signals, checks who audited them before, and shows which contributors connect them to existing clients.

Started in n8n to test the idea, then rebuilt in Python once it proved useful. Cold-outreach reply rate went from 13% to 21%.
